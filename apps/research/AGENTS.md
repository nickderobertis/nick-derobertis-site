# Research rules

This remote publishes the `/research` route page.

## Journeys

1. Working papers, works in progress, and the category groupings render, and
   coauthors and resources appear only when a project has them, through both the
   standalone remote and the host-composed route.
2. Its skeleton shows while the data boundary is pending and then renders, its
   empty state is visible, and it recovers with an error state when the boundary
   fails.
3. Project panes reflow on a narrow viewport and fit each captured viewport.
