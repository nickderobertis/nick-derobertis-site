# Skills rules

This remote publishes the Home skills pane and its standalone document.

## Journeys

1. The recursive skills tree renders, stats are revealed on hover and keyboard
   focus, a category drills in and back out, and the accessible dropdowns browse
   skills, through both the standalone remote and the host-composed Home page.
2. Its loading, empty, and error states are presented and an invalid preview
   state is rejected, through both render paths.
3. It stays responsive at each viewport, and the standalone remote loads the
   shared design-system.
